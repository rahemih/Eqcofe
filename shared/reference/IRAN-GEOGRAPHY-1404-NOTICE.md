# Iran Geography Reference Data — 1404

EQCOFE vendors a normalized province/city subset derived from:

- Repository: `Hameds/IranCountryDivisions`
- Source commit: `68687cf96cc1852d5d38c7283353c80829331758`
- Upstream dataset metadata: `مرکز آمار ایران - فایل جغرافیایی سالانه`, year **1404**
- Imported source file: `packages/npm/data/1404/core.json`
- Upstream repository license: **MIT**

The EQCOFE-generated UUIDs are internal stable reference identifiers for the frozen 1404 snapshot. They are not government-issued identifiers. They are generated centrally by the repository reference layer and must never be invented by browser/UI code.
