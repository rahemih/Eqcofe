# Project Overview

**EQCOFE — Equipment Coffee** is a Persian/RTL e-commerce platform focused on coffee equipment and accessories for retail (B2C) and approved wholesale (B2B) customers.

The backend is a SQL-first modular monolith. The current canonical source contains API, Worker and Scheduler processes and is complete through Step 44. Frontend/admin implementation is planned in Steps 53–58.

Canonical project constraints include Toman-based money, no wallet, strong module ownership, fail-closed provider integrations and launch scope control.
