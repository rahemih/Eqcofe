# Canonical Import Strategy

This repository uses a **transparent import baseline**, not fake historical commits.

The old GitHub repository contained valid traceability and recovery evidence but was not a complete source mirror. The current application tree was therefore imported from the final verified Step44 artifact. Historical evolution is represented in documentation, source-audit evidence, old repository references and artifacts.

A single baseline Git commit/tag is appropriate for the new repository. Historical dates/commits are not recreated synthetically.
