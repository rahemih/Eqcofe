## Focus and keyboard

- entry: Focus page heading; RTL logical reading, LTR isolate SKU/codes/versions. Tables use labelled card equivalents at compact widths.
- dialog: Initial focus safe cancel; trap Tab within modal, Escape cancels and restores trigger. Step-Up follows B secure-auth pattern.
- error: Focus linked error summary after failed submission, with inline descriptions; retain input and do not move focus on every blur.
- navigation: Keyboard reaches every task and field;44px touch targets, no drag-only control, no fixed footer obscuring focus; polite authoritative result announcement.

Long Persian wraps; text spacing and user font overrides must not clip. Browser-runtime keyboard/screen-reader certification is deferred to implementation; these are design obligations.
