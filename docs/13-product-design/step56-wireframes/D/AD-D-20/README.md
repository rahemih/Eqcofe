# AD-D-20 — پیش‌نمایش و اعمال کالای اکسل

Catalog apply resolves existing products/variants; only product name/status and variant barcode are applied, versions included in preview hash. Recomputes preview, rejects stale hash; Step-Up and excel.catalog.apply idempotency. No new product creation or combined catalog-and-price atomic transaction. Server permission and owner policy remain authoritative; inherited source gaps are NO_ACTION. UI review never grants permission.

- error: Focus linked error summary after failed submission, with inline descriptions; retain input and do not move focus on every blur.
- navigation: Keyboard reaches every task and field;44px touch targets, no drag-only control, no fixed footer obscuring focus; polite authoritative result announcement.
