# SF-E-01 — پیشخوان حساب کاربری

**Gate:** 55-E  
**Fidelity:** structural low-fidelity  
**Route intent:** `/account`  
**Actors:** retail، wholesale-applicant، wholesale

## هدف

کار اصلی **دیدن خلاصه قابل اعتماد حساب و اقدام‌های مهم** است. اقدام اصلی «مشاهده سفارش‌های من» و بازیابی bounded «تلاش دوباره فقط برای بخش ناموفق» است. ترتیب محتوا هویت و امنیت ← سفارش‌های اخیر ← خدمات مشتری ← وضعیت عمده ← علاقه‌مندی و امتیاز می‌ماند و reflow ترتیب معنایی را عوض نمی‌کند.

## مالکیت و امنیت

صفحه فقط منبع customer-owned همان Session را می‌خواند. UI نتیجه approval، eligibility، سفارش، پرداخت، مرجوعی یا گارانتی را اختراع نمی‌کند. denied وجود رکورد دیگر را افشا نمی‌کند؛ شناسه‌های Latin bidi-isolated و اطلاعات شخصی ماسک می‌شوند.

## حالت‌ها

| State | عنوان | زمینه | اقدام bounded |
|---|---|---|---|
| `initial` | خلاصه حساب آماده است | سفارش اخیر، نشانی و ابزارهای مشتری از منابع authoritative نمایش داده می‌شوند. | مشاهده سفارش‌های من |
| `unauthenticated` | نشست شما پایان یافته است | برای دسترسی دوباره OTP لازم است؛ هیچ داده شخصی یا سفارش نمایش داده نمی‌شود. | ورود امن به حساب |
| `partial` | بخشی از اطلاعات در دسترس نیست | پروفایل و سفارش‌ها حاضرند اما امتیاز مشتری بارگذاری نشد؛ سایر بخش‌ها قابل استفاده می‌مانند. | تلاش دوباره برای امتیاز |

Empty، partial، validation، conflict، pending، terminal و failed معنای جدا دارند. ورودی امن در خطا حفظ می‌شود؛ submitting درخواست تکراری نمی‌سازد و recovery فقط همان منبع authoritative را دوباره می‌خواند.
