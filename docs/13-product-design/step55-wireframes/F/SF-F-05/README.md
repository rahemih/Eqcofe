# SF-F-05 — پرسش‌های پرتکرار

**Gate:** 55-F

**Fidelity:** structural low-fidelity

**Route intent:** `/faq`

**Actors:** guest، retail، wholesale-applicant، wholesale

**Operation trace:** static-approved-content

## هدف

کار اصلی **یافتن پاسخ کوتاه و مصوب پیش از تماس** است. اقدام اصلی «بازکردن پاسخ» و بازیابی bounded «پاک‌کردن جست‌وجو یا رفتن به تماس» است. ترتیب محتوا جست‌وجو ← موضوع‌ها ← پرسش ← پاسخ ← پیوند سیاست/فرایند ← تماس می‌ماند.

## حقیقت محتوا و سیاست

Published content، نسخه سیاست و پاسخ مصوب از منبع مالک خود می‌آیند. صفحه static هیچ API یا mutation ساختگی ادعا نمی‌کند. no-result با failed متفاوت است، ورودی امن حفظ می‌شود و retry فقط همان query را تکرار می‌کند.

## حالت‌ها

| State | عنوان | زمینه | اقدام bounded |
|---|---|---|---|
| `initial` | پاسخ‌های پرتکرار آماده‌اند | پرسش‌های سفارش، پرداخت، ارسال و عمده‌فروشی با پاسخ مصوب نمایش داده می‌شوند. | بازکردن پاسخ پرداخت |
| `no-result` | پاسخی برای این عبارت پیدا نشد | عبارت حفظ می‌شود و تماس به‌عنوان مسیر بعدی بدون ادعای SLA در دسترس است. | پاک‌کردن جست‌وجو |
| `failed` | پرسش‌ها بارگذاری نشدند | پاسخ قدیمی یا حدسی نمایش داده نمی‌شود و retry bounded است. | تلاش دوباره |

Draft، scheduled content، قانون حدسی، eligibility قطعی، SLA یا کانال ساختگی نمایش داده نمی‌شود. پرداخت، مرجوعی، گارانتی و عمده‌فروشی همچنان به حقیقت authoritative مراحل قبلی ارجاع دارند.
